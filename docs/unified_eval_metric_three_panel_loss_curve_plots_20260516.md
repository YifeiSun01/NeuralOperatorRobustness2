## New Three-Panel Unified-Evaluation Figures

The new script added for the old three-panel layout is:

```text
tools/plot_batch_eval_metric_three_panel_curves.py
```

It keeps the old visual structure:

- one figure per optimized-loss family;
- three stacked panels for the optimized objective variant:
  `original`, `increment_ratio`, `regularized`;
- three method curves in each panel:
  PGD, LP-steepest PGD, generalized power iteration.

The difference is that each figure fixes one shared evaluation metric on the
y-axis. For example:

```text
loss3_evaluated_by_loss3_original_init_zero_three_panel_mean_std.png
```

means:

- all three panels come from attacks that optimize `loss3`-family objectives;
- the three panels still correspond to original / increment-ratio /
  regularized attack targets;
- every curve in every panel is evaluated by the same y-axis metric:
  `loss3_original`;
- all three panels share the same y-axis min/max range.

This directly fixes the old ambiguity: the plot now compares different
optimization targets using the same evaluation loss.
