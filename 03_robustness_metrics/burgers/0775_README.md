## Main reading

- Prediction loss 上，loss1 epoch2000 的 test/generalization 都非常强；loss2 epoch1000 的 train/test 很低，但没有 Jacobian/SVD 已算结果。
- 已有 Jacobian/SVD 结果里，loss1 epoch2000 的 `||J_model-J_solver||_2` 最低，是当前最接近 solver 的 checkpoint。
- loss2 epoch900 第二强；loss3 epoch800 是 loss3 系列里较好的点，但 loss3 epoch1000 在 Jacobian error 和 vector similarity 上反而比 epoch800 弱。
- baseline 已补入 model-vs-solver singular-vector similarity，方便和训练后模型对比。
