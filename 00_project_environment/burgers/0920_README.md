# NS2D And Burgers Cleanstyle Figures

- `NS2D/`: NS2D heatmaps, delta spectra, and loss curves. Includes `Epsilon = 160, Alpha = 50` if present.
- `Burgers/`: Burgers line panels, delta spectra, and unified loss3 curves.


- `NS2D/optimizer_grouped_loss_curves/` and `Burgers/optimizer_grouped_loss_curves/`: fixed-target loss curves comparing the four optimizers.

- `NS2D/optimizer_grouped_loss_curves/all_eps/`: one optimizer comparison figure per available NS2D epsilon/alpha setting.
