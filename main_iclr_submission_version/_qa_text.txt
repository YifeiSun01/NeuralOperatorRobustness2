009                                               A BSTRACT
010
011            Neural operators are widely used as fast surrogates for numerical PDE solvers,
012            mapping input functions to solution functions. However, their generalizability and
013            robustness are not yet clearly defined in the operator-learning setting, which dif-
014            fers from traditional adversarial robustness definitions. This paper studies the gen-
015            eralizability and robustness of a learned neural operator from a solver-integrated
016            perspective, addressing the challenge that the output of a learned operator and a
017            numerical solver tends to change in tandem under input perturbation. First, we
018
               formalize the definition of generalization and robustness through a model-solver
               error operator, identifying fixed-input model-solver loss as generalization metric,
019
               and norm-bounded adversarial attack loss increase and Jacobian-error function
020
               norm as robustness metric. Second, we identify the solver-integrated adversar-
021            ial attack as appropriate for PDE operator learning and show why model-only or
022            fixed-ground-truth attacks can be insufficient when the solver output also changes
023            with the input. Third, we develop solver-integrated adversarial training methods
024            for neural operators. Experiments on representative PDE benchmarks show that
025            this solver-integrated adversarial training clearly improves both generalizability
026            and robustness. Deeper solver integration yields more effective attacks, more in-
027            formative samples, and more efficient training than less integrated alternatives.
028            More broadly, this paper is a carefully chosen instance of a wider adversarial-
029
               regression setting: the PDE solver provides a ground-truth oracle that reveals how
               true outputs change under input perturbations and supplies their input gradients,
030
               information unavailable in many prior problem settings.

      1   I NTRODUCTION
034
035
      Neural operators, including Fourier Neural Operators and DeepONets, learn maps between function
036   spaces and are widely used as fast data-driven surrogates for numerical PDE solvers (Li et al., 2021;
037   Lu et al., 2021). They map input functions to solution functions in one forward pass, making them
038   attractive when many related PDE solution queries are needed. Practical use, however, requires
039   the learned operator to generalize beyond the training dataset and remain close to the solver when
040   the input function is perturbed. Recent neural operator studies have therefore begun to examine
041   adversarial robustness and robustness-aware training (Adesoji & Chen, 2022; Huang et al., 2026;
042   Roy et al., 2026a).
043   Prior work has often not clearly separated the notions of generalization and robustness. Classical
044   theory defines generalization through expected-versus-empirical loss (Bousquet & Elisseeff, 2002;
045   Xu & Mannor, 2012). Several modern robustness notions are defined by worst-case loss increase
046   under norm-bounded perturbations (Madry et al., 2018), and global Lipschitz constants and local
047   spectral norms are also used to measure robustness (Cissé et al., 2017; Huang et al., 2026). We
048   inherit these ideas and specialize them to the operator learning setting. Generalization is a static
049   definition: the norm of the output of our error operator. Robustness is defined in a dynamic way:
050
      how the output of our error operator amplifies under an input perturbation. We further develop
      Jacobian-error, which is cheaper to compute and closely aligned with adversarial loss increase in the
051
      local robustness setting.
052
053   Most classical adversarial attacks were developed for classification models, where it is reasonable to
      assume that a small input perturbation should not change the ground-truth label (Goodfellow et al.,


                                                        1
      Under review as a conference paper at ICLR 2027




054
      2015; Madry et al., 2018). However, the PDE operator learning problem is not only a regression
055   problem, but a regression problem with an existing numerical solver as a trusted oracle. When the
056   input function is perturbed, the correct solution should change accordingly but stay close to the
057   solver’s output. Therefore, the model is not expected to be robust by itself; rather, the model-solver
058   discrepancy is expected to be robust. We therefore define the error operator as the discrepancy
059   between the learned operator and the solver.
060
      Building on this view, we develop solver-integrated adversarial training. The method is a teacher-
061   student solver distillation procedure: the numerical solver is the oracle teacher, and the neural op-
062   erator is retrained on informative inputs where the local model-solver discrepancy is large. This is
063   the special opportunity that makes the framework operational here: in ordinary regression or vision
064   problems, perturbing an input can also change the true output, yet the true input-output map and
065   its gradient are usually unavailable; in PDE operator learning, the solver can relabel each perturbed
066   input and can be differentiated through. Experiments show that exploiting this oracle improves gen-
067   eralization and robustness. More broadly, the paper should be read as a carefully chosen instance of
068   a broader adversarial-regression problem with access to a ground-truth oracle, rather than as a claim
069
      limited to neural operators alone.
070   Our main contributions can be summarized as follows:
071
072          • In the setting of operator learning, we propose a new robustness definition and metric.
073          • We identify the most accurate and appropriate target loss for neural-operator adversarial
074            attack, which involves deep solver integration.
075          • We propose solver-integrated adversarial training for neural operators to improve both gen-
076            eralization and robustness.

078   2   R ELATED W ORK
079
080   Traditional adversarial attacks. Most classical adversarial attacks were designed for classification,
081   where the objective is usually to maximize a label loss such as ℓ(fθ (x + δ), y) under a perturbation
082   constraint (Goodfellow et al., 2015; Madry et al., 2018). These attacks mainly differ in the op-
083   timization procedure, perturbation constraint, sparsity or structure, or available information, while
084   retaining the assumption that the ground-truth label remains fixed (Carlini & Wagner, 2017; Papernot
085   et al., 2016; Moosavi-Dezfooli et al., 2016; Brendel et al., 2018; Chen et al., 2020; Andriushchenko
086   et al., 2020; Su et al., 2019; Brown et al., 2017; Croce & Hein, 2020). Regression attacks and time-
087
      series forecasting attacks have also been studied (Nguyen & Raff, 2019; Tong et al., 2018; Ribeiro
      et al., 2023; Mode & Hoque, 2020; Liu et al., 2023). Their target losses use a fixed observed la-
088
      bel or the model’s own output. They do not recompute the true loss with the true output for the
089
      perturbed input inside the attack loop. They acknowledge that the true output should change ac-
090   cordingly with input perturbations, but lack the generating function in that setting. Therefore, they
091   assume that small perturbations do not meaningfully change the observed label. However, in our
092   operator-learning setting, the numerical solver is exactly this generating function, so the true output
093   and the corresponding true loss can be recomputed for each perturbed input inside the loop. Under
094   the framework below, previous attack losses contain relatively little solver integration and fall into
095   the first two target-loss categories, L1 and L2 .
096   Neural-operator adversarial attacks. A closer study evaluates adversarial robustness for oper-
097   ator learning and finds that neural-operator error can grow significantly as the perturbation norm
098   increases (Adesoji & Chen, 2022). Although solver outputs are used as references, the solver is not
099   truly integrated into the attack loop. In the forward pass, the solver output for an updated perturbed
100   input is approximated by a nearest-neighbor ground-truth output from a precomputed dictionary;
101   in the backward pass, the solver gradient is ignored and only the neural-operator gradient is used.
102   Besides, this study focuses on adversarial robustness evaluation for neural operators, but does not
103   propose a method for improving the model’s adversarial robustness.
104   PDE-problem adversarial training. WbAR combines adversarial training with PINNs by moving
105   collocation points toward larger PDE residuals (Shi et al., 2026); StablePDENet applies adversarial
106   training to neural operators with a physics loss (Huang et al., 2026); and RAMS systematizes this
107   residual-gradient sample movement for PINNs and operator learning (Ouyang et al., 2025). These
      methods do not use true solver outputs as supervised targets inside the adversarial loop. Instead,


                                                        2
      Under review as a conference paper at ICLR 2027




108
      they use physics loss as a surrogate loss. The drawbacks are that this physics loss is less informative
109   than direct solver supervision and that, in many time-dependent neural operator settings, the model
110   outputs only one single frame of the final state, so the temporal derivatives required by a physics loss
111   are unavailable. Other operator-learning works use heuristic, active, or generative sampling: neural-
112   operator digital-twin studies use gradient-free sparse attacks and attack-driven active learning with
113   input denoising (Roy et al., 2026b;a), while adversarial autoencoders, GANO, and turbulent-flow
114   generative models use distributional or generative objectives (Enyeart & Lin, 2024; Rahman et al.,
115   2022; Oommen et al., 2025). These sampling strategies can be useful, but they are heuristic or
116   distributional rather than chosen according to the current solver-model discrepancy, and they do not
117
      use solver gradients to choose perturbation directions.

      6   C ONCLUSION
453
454
      This paper studies the generalizability and robustness of neural operators from a solver-integrated
455   perspective. We define both quantities through model–solver discrepancy under distribution shift
456   and adversarial perturbation, show why model-only robustness indicators are insufficient for PDE
457   operator learning. We then propose a solver-integrated adversarial attack whose forward loss and
458   backward gradient both use the PDE solver, so the attack directly maximizes the relevant model–
459   solver error. From this attack, we derive an adversarial-training procedure that generates solver-
460   relabelled adversarial batches online. Experiments on Burgers, Darcy Flow, and Navier–Stokes set-
461   tings show that this solver-integrated adversarial training clearly improves both generalizability and
462   robustness over non-solver-integrated objectives, without manually selecting special shifted train-
463
      ing datasets. More broadly, the framework is not limited to operator learning: any neural-network
      system with access to a ground-truth oracle can adopt this formulation for adversarial attacks and
464
      adversarial training.
465
466   The main limitation is computational cost. Solver-integrated attacks and training require expen-
467   sive solver forward passes and gradients through the solver. For time-dependent PDEs, the solver
468   backward pass must keep the intermediate states and stage variables from many time steps in GPU
469
      memory so that gradients can be propagated back through the entire rollout. This creates a large
      memory footprint and a long wall-clock time cost, especially for NS.

       The solver-tape discussion above explains the large cost gap between the steady Darcy Flow solver
1148   and the time-dependent Burgers/Navier–Stokes solvers. Darcy Flow is a steady elliptic solve rather
1149   than a temporal rollout; operationally, it is closer to one stationary solve than to thousands of small

1151   time-dependent solvers, the first storage lower bound is simply the number of time steps times the
1152   number of spatial grid points. Burgers gives about 1001 · 1024 stored physical-state values. Navier–
1153   Stokes is much larger: 4001 · 256 · 256 values, which is about 1 GB per sample for one float32
1154   physical field alone. The actual differentiable tape is larger because each time step also stores
1155   Fourier/physical transforms, velocity and gradient fields, nonlinear terms, and ETDRK4 stage states.
