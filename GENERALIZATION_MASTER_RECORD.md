# Neural Operator Generalization Master Record

This Markdown file is the single record for the selected trained models, the generated generalization datasets, dataset parameters, paths, file sizes, similarity ranking, and evaluation outputs.

## Related Work Notes

- Neural operator adversarial robustness has been studied, for example in `Evaluating Adversarial Robustness in Fourier Neural Operators` (`https://arxiv.org/abs/2204.04259`). This is close to adversarial attack/robustness evaluation for FNOs.
- Adversarial objectives also appear in GAN-style neural-operator work, for example `Physics-informed Generative Adversarial Networks with Neural Operators` (`https://arxiv.org/abs/2205.03017`). This is adversarial learning in the GAN sense, not exactly PGD adversarial training.
- Active-learning neural-operator work exists under keywords such as active learning for neural operators, adaptive sampling, uncertainty-guided operator learning, and multifidelity operator learning. The generated datasets here can support that direction by identifying which distribution shifts deserve new training samples.

## Training Distribution References

- `burgers`: 1D Gaussian GRF initial condition, periodic boundary condition, `correlation_length=0.03`, `nx=1024`, `nu=0.001`, `t_final=1.0`, seed `45`.
- `darcy`: 2D Neumann-Laplacian cosine-mode GRF latent field, `alpha=2`, `tau=3`, thresholded into binary coefficients `3` and `12`, model resolution `85`, solve resolution `421`, seed `45`.
- `ns2d`: 2D Zongyi real initial conditions, spectrally upsampled to `256x256`, Exponax Navier-Stokes rollout, `nu=1e-5`, `t_final=20`, `21` saved frames.

## Generated Dataset Design

- Each task has exactly `50` generated generalization datasets.
- `burgers`: each generated dataset has `200` samples, tensors `x/y=(200,1024)`.
- `darcy`: each generated dataset has `200` samples, tensors `x/y=(200,85,85)` plus `latent`; coefficient fields are binary or contrast-shifted variants.
- `ns2d`: each generated dataset has `50` samples, tensors `x=(50,256,256)`, `y=(50,256,256,21)`.
- Similarity tiers: `near_param_shift` is closest, `mid_kernel_spectrum` changes covariance/spectrum/morphology, and `far_range_pattern` changes range/sign/nonlinear pattern/contrast strongly.

## Notes On Similarity Ranking

- Manual tier records how the dataset was intentionally generated relative to training: near, middle, or far.
- `feature_distance_to_train` is computed from dataset-level statistics of the input/initial field: mean, standard deviation, min, max, RMS, and low/mid/high spectral fractions.
- For Darcy, the feature distance also includes binary high-value area fraction and edge density, because Darcy generalization depends strongly on binary material morphology.
- Bar plots use train and test first, then generated datasets sorted by `feature_distance_to_train` from closest to farthest.

## Loss Design Note

- Fourier/Parseval note: `FOURIER_DOMAIN_LOSS_PARSEVAL_NOTE.md`
- For ordinary L2/MSE loss, physical-space pointwise loss and total Fourier-domain energy loss are equivalent up to FFT normalization. Fourier-domain loss is only needed for frequency-weighted or frequency-band diagnostics.

## Storage Reminder

- The generated datasets are intentionally small per distribution but large in aggregate because NS2D stores full `256x256x21` trajectories.
- Total generated dataset storage is approximately `15 GB`, dominated by `generalization_datasets/ns2d`.
