# Adversarial Training Run

- Run directory: `adversarial_training_runs/smoke_solver_label_darcy_exact_fixcheck`
- Tasks: `darcy`
- Smoke: `False`
- Label mode: `solver`

Each task subdirectory contains `train_steps.csv`, `attack_batches.csv`, `eval_metrics.csv`, `memory.csv`, checkpoints, `data_range_summary.json`, and `summary.json`.
Default training now uses the full original train split for every epoch; pass `--<task>-train-max N` only for debugging caps, or `0` for full.

Default attack policy:
- Burgers: short L-infinity fast-replace attack; attack and training targets are recomputed with the Burgers solver.
- Darcy: binary steepest-replace flips coefficient pixels; scoring and training targets use the JAX Darcy solver.
- NS2D: L-infinity add attack on the initial vorticity frame; input and target sequences are regenerated by NS solver rollout.

Evaluation is clean evaluation on train/test/generated datasets at baseline and at scheduled progress fractions.
