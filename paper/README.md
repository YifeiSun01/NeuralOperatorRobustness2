# Solver-Integrated Adversarial Attacking and Training of Neural Operators

This is the working AAAI-style LaTeX project for the paper.

Main files:

```powershell
main_aaai_submission.tex
references.bib
research_notes.md
aaai2027.sty
aaai2027.bst
```

Compile with the local TinyTeX installation:

```powershell
.\.localtex\TinyTeX\TinyTeX\bin\windows\latexmk.exe -pdf main_aaai_submission.tex
```

The compiled PDF is written to:

```powershell
main_aaai_submission.pdf
```
